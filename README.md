# Busya-PDF-to-image-convecter
Busya PDF to image

Busya PDF to image — это удобный и безопасный инструмент от проекта Busya™, предназначенный для быстрой локальной конвертации PDF-документов в графические форматы. Приложение создано с упором на утилитарность, защиту пользовательских данных и полную независимость от облачных сервисов.

Ключевые преимущества:

Полностью офлайн работа: Вся конвертация файлов происходит исключительно на вашем устройстве. Документы никуда не выгружаются и не обрабатываются на сторонних серверах, что гарантирует абсолютную приватность ваших данных.

Абсолютно бесплатно: Все функции доступны сразу, без скрытых подписок, лимитов на количество страниц или водяных знаков на готовых фотографиях.

Без рекламы и сбора данных: Чистый интерфейс без отвлекающих баннеров. Приложение не содержит трекеров отслеживания активности и не отправляет аналитику в фоновом режиме.

Открытый исходный код: Полная прозрачность разработки. Исходный код открыт и доступен для проверки любым желающим.

Детальная настройка экспорта: Гибкий выбор степени сжатия (от 1% до оригинального качества) и поддержка широкого спектра форматов для сохранения (JPG, PNG, WebP и другие).

Адаптивность и локализация: Встроенная поддержка 8 языков, выбор светлой, тёмной или собственной темы оформления, а также специальный режим интерфейса для левшей.



Примечание о Firebase:
В коде скомпилированного APK вы можете найти библиотеки Firebase. Они автоматически добавляются сборщиком приложений по умолчанию. Наше приложение не использует их и не отправляет запросы к серверам аналитики.
